# ZeniMusic Architecture — Note 10

## Module notes (documentation series, part 10 of 16)

ZeniMusic is a native Android music player built with Kotlin and classic
Android Views. Audio is extracted from YouTube via NewPipe Extractor and
played through Media3 (ExoPlayer) with background playback support.

### Topic 10
This file is part of a documentation series expanding the project notes.
Each part covers one aspect of the codebase layout and player pipeline:
service lifecycle, notification controls, queue management, podcast
directory, radio recommendations, offline downloads, and the sync'd lyrics
viewer.
